Number Of Units Per Nationality : ID 10156

Question -> Write a query that returns how many different apartment-type units (counted by distinct unit_id) are owned by people under 30, grouped by their nationality. Sort the results by the number of apartments in descending order.


Table -> airbnb_hosts
age:bigint
gender:text
host_id:bigint
nationality:text

airbnb_units
city:text
country:text
host_id:bigint
n_bedrooms:bigint
n_beds:bigint
unit_id:text
unit_type:text

################################################################################
SOLUTION->

select  
ah.nationality,
count(distinct au.unit_id) as apartment_count
from airbnb_units au 
join airbnb_hosts ah on au.host_id = ah.host_id
where ah.age < 30 and au.unit_type = 'Apartment'
group by ah.nationality
order by apartment_count desc
;
